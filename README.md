# VR Exposure Therapy

This repository is a separated copy of the "Exposure Therapy / VR Tour" project. It contains the exposure-therapy-focused HTML pages and helper scripts.

Files included:
- `phobia.html` — exposure therapy page (main)
- `index.html`, `index2.html`, `resolution.html` — copied helpers/tests
- `serve.py`, `start-share.sh` — local server and share helper (ngrok)
- `.gitignore`, `.vscode/settings.json`

Assets (images, videos, sounds, 3D models, and the local A-Frame build) are large binary files and were not copied automatically. See `ASSETS_TO_COPY.txt` for the list and commands to transfer them from the original workspace.
